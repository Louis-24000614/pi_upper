# 道路覆盖与未知路障演示

本演示位于 `pi_upper/demo/`，复用 `config/nav_topology.yaml` 和 `navigation/topo_proto/graph.py`。运行环境需 Python 3.10+、PyYAML；图形界面还需 Python 自带的 Tkinter。它不接入实车控制。

在 `pi_upper` 目录运行：

```powershell
python -m demo
```

点击三条道路的**中段**预设路障，然后点“开始 / 单步 / 自动”。红方块展示预设位置，车辆规划器起初不知道障碍。驶入障碍所在边约 1/4 后才发现，立即封边和重规划；下一步掉头退回入口节点，再按新路线继续。绿色表示已走道路，深绿是下一段。

无界面运行和列出边 ID：

```powershell
python -m demo --list-edges
python -m demo --headless --obstacles 1_2__2_2 2_1__2_2 3_1__3_2
```

## 规划规则

- 初始目标是走遍已知道路并回到出发区；初始全边必经时，用奇点最小权匹配求无向中国邮递员路线。
- 障碍预设只存在仿真状态中。车辆尝试进入该道路后才发现、封边并重新规划。
- 重规划仅将尚未走过且仍可通行的边列为必经；已走道路可以作为连接路线再次通过，封闭道路不再尝试。
- 剩余必经边若分成多个不相连的块，先用最短路贪心连接，再做奇点匹配。这一阶段保证生成可行覆盖路线，但不保证数学意义上的全局最短。
- 若封边导致道路或出发区不可达，程序会报告未覆盖道路或任务无法返回。障碍在路段中间、掉头回到入口是离散仿真事件，没有模拟真实车辆转弯半径、制动距离和视觉检测误差。
