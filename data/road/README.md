# 道路分割实采

原始 BGR 帧以 PNG 写到本目录。文件名：`nav_时间戳.png` 或 `rec_时间戳.png`。构图用 `gui/snap_view.sh`（香橙派 HDMI）或 `gui/webcam_stream.sh`（自己电脑的浏览器，打开页面后点「拍照」）。上位机里的「拍照」保存的也是这一份原始帧，但预览会被缩小裁边。

这些图用于赛题要求的纯视觉道路分割训练。PNG 本身不入库。

## 白底白沿约定

正式场可能是 **路面 / 侧沿 / 岛区同色**，只有约 2–5 cm 高度差，没有可靠黑边。采集与标注必须按此最坏情况准备：

1. **练车场**：同色刷白 + 真实高度矮沿；黑胶带图最多作小比例对照（建议 &lt;15%）。
2. **标注 `road`**：只标可行驶 **底面**；侧沿顶面/立面、岛区、场外不要标成路。
3. **可选 `curb`**：侧沿可见立面+顶面，帮助钉边界。
4. **交叉口**：可见可行驶底面都标 `road`。
5. **覆盖**：直道/弯道/偏航/远近、侧向阴影、顶光过曝；不要只拍「画面中间一块白」。
