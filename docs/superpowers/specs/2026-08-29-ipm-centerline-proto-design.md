## 目标

1. 实现 IPM（单应 / 外参）把前视 road mask 变到鸟瞰栅格。
2. 在 BEV mask 上提取米制中心线（近端权重大）。
3. 提供合成直道数据与单元测试，不依赖相机与模型。
4. 提供 CLI：读图/mask/配置，写出 BEV 与中心线叠加图。

非目标：YOLOv11、RKNN、Pure Pursuit、UART、Qt。

## 目录与模块

均在 `vision/ipm_proto/`：

| 文件 | 职责 |
| --- | --- |
| `ipm.py` | 构建单应、warp 到 BEV、像素↔米 |
| `centerline.py` | BEV mask → 中心线点列 |
| `synth.py` | 合成透视道路图 + mask |
| `cli.py` | 命令行入口 |
| `config_example.yaml` | 外参 / BEV 窗口示例 |
| `tests/` | 合成直道几何断言 |

模块说明见 `docs/reference/perception/ipm_proto.md`。

## 坐标系与配置

- 车体 / 地面：\(X\) 向右为正，\(Y\) 向前为正，原点在相机光心在地面投影附近（可由配置平移）。
- BEV 图像：行对应 \(Y\)（默认图像上方为远端、下方为近端），列对应 \(X\)。
- 配置项：相机高度与俯仰（或图像四点↔地面四点）、BEV 范围（默认前 0.3–1.5 m、横向 ±0.5 m）、分辨率（m/pixel）。

## 算法约定

- IPM：平面地面假设；优先用外参推单应，也支持直接给 4 点对应。
- 中心线：对每个 \(Y\) 切片取 road 像素的 \(X\) 中位数（或左右边界中点）；无道路像素则跳过；输出 `[(x,y), ...]`（米）。
- 合成：生成已知路宽约 0.8 m 的直道透视场景，供回归测试。

## 验收

- 合成直道：BEV 上测得路宽与 0.8 m 误差在合理阈值内；近端中心线 \(|X|\) 接近 0。
- `python -m vision.ipm_proto.cli ...`（或包内入口）能产出可视化 PNG。
