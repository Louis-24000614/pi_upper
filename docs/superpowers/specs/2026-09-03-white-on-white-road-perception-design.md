# 白底白沿道路感知设计

杭州侦察机器人场地在最坏情况下：**路面、侧沿、岛区同色白木板，几乎只有高度差（约 2–5 cm）**，没有黑胶带一类的颜色边线。本文规定 Stage-1 寻线在此假设下的感知与几何兜底策略；控制与拓扑仍分别见 Stage-1 / `docs/nav.md`。

## 问题与目标

**问题：** 颜色阈值或依赖黑边训练的分割，在同色场上会失效或极不稳定。

**目标**

1. 用 **几何/阴影线索** 训练 YOLO-seg（`road`，可选 `curb`），而不是色差。
2. 用匹配的同色练车场与推荐相机姿态，让侧沿立面在近端形成可学细带。
3. 在 BEV 层用 **路宽先验（约 800 mm）+ 时间平滑** 抑制单帧过分割/抖边。
4. 若 A 路径实车仍不稳，再评估 **双目测沿**（仍属摄像头，尽量保纯视觉加分）。

## 练车场与相机姿态

### 练车场清单

- [ ] 路面、侧沿、岛区 **同刷白或同材质**，避免「只有黑胶带才像路沿」。
- [ ] 安装 **真实高度** 侧沿（按现场 20 mm 或 50 mm；按最矮 20 mm 准备）。
- [ ] 黑胶带仅可作对照子集，**不得主导**训练集。
- [ ] 覆盖直道、弯道、偏航、交叉口、侧向阴影、顶光过曝。
- [ ] 隧道/无光另采，不与亮场同色问题混为一谈。

### 相机姿态（导航前视）

目标：让侧沿 **立面** 在画面近端形成稳定细带，而不是被压成一条几乎看不见的线。

| 项 | 推荐初值 | 说明 |
| --- | --- | --- |
| 安装高度 | 0.20–0.28 m | 过高俯视会吃掉 2 cm 沿 |
| 俯仰（下倾） | 22–32° | 略俯视；过大俯视同样压扁立面 |
| 分辨率 | 1280×720 或更低 | 保 NPU/带宽 |
| 光心横向 | 尽量车体中线 | 减少固定偏置 |

权威数值写入 [`config/nav_camera.yaml`](../../../config/nav_camera.yaml)，实车标定后只改配置不改代码。

## 数据与标注

| 项 | 约定 |
| --- | --- |
| 采集 | GUI「拍照」→ `data/road/`（见 `gui/README.md`） |
| 主类 `road` | **仅可行驶底面**；侧沿顶面/立面、岛区、场外 **不标为 road** |
| 可选 `curb` | 侧沿可见立面+顶面；帮助钉边界；推理时可并入「非可行驶」 |
| 交叉口 | 所有可见可行驶底面标 `road`；方向留给拓扑层 |
| 负样本 | 故意拍偏航、半出界、强阴影，避免只学「画面中间一块白」 |

当前仓库里带黑胶带的历史图：可保留作小比例对照，**新主集必须是同色矮沿**。

## 训练增强

训练主机（如 4070Ti）上对 YOLO-seg 加大外观扰动，逼模型用几何：

- 亮度/对比度/伽马大范围抖动
- 随机阴影条带、局部暗角
- 白平衡与色温偏移
- 轻微运动模糊
- **不要**依赖「把边染成黑色」的增强当主线索

示例超参见 [`config/road_seg_train.yaml`](../../../config/road_seg_train.yaml)（Ultralytics 风格；主机按本机环境微调）。

## 推理与几何兜底

```text
YOLO-seg → road mask
        → IPM/BEV
        → 路宽先验选带 / 裁切过宽行
        → 中心线
        → 时间平滑（EMA）
        → Pure Pursuit / 失效停车
```

实现位置：`vision/ipm_proto/prior.py`、`temporal.py`；由 `extract_centerline` 流水线或 CLI 调用。

| 参数 | 默认 | 含义 |
| --- | --- | --- |
| `expected_width_m` | 0.8 | 赛题路宽 |
| `min_width_m` | 0.35 | 过窄行丢弃（噪声） |
| `max_width_m` | 1.15 | 超过则按期望宽围绕优选中心裁切 |
| `smooth_alpha` | 0.45 | 帧间 X 的 EMA 系数（越大越跟新帧） |

mask 点数过少或平滑后近端无法形成中心线 → 与 Stage-1 一致：**减速/停车**，不沿旧线冲刺。

## RKNN 部署与验收

部署路径不变：训练 → ONNX → RKNN-Toolkit2 → `models/*.rknn`（不入库）。

亮场验收（同色练车场）：

1. 直道：居中行驶，不持续蹭侧沿。
2. 缓弯：跟线，不冲出底面。
3. 故意遮挡/大偏航：减速停车。
4. 合成/单元：`PYTHONPATH=vision python3 -m ipm_proto.tests.test_pipeline` 与先验相关用例通过。
5. 端到端延迟目标与 Stage-1 相同（&lt; 100 ms，可按实车调）。

## 双目测沿后备

仅当单目分割 + 先验在同色场上 **连续验收失败** 时启用评估，不作为第一周主线。

| 项 | 建议 |
| --- | --- |
| 传感器 | 双目摄像头（仍计摄像头；避免超声/激光/主动红外以保加分） |
| 目标 | 检测 20–50 mm 高度不连续，得到左右沿带 |
| 基线 | 短基线 + 较高分辨率；2 cm 台阶对标定与噪声敏感 |
| 融合 | 沿带投影到 BEV，与 road mask 求交或约束中心线 |
| 风险 | 标定漂移、算力、隧道无纹理 |

评估清单见 [`docs/reference/perception/stereo_curb_fallback.md`](../../reference/perception/stereo_curb_fallback.md)。
